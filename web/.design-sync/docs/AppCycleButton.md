A pill that steps to its next value each time it is tapped, for a setting of
two or three values that has to change mid-activity — one hand, no sheet, no
slider. The value rides on the control, so reading it and changing it are the
same glance, and `label` says both the value now and that a tap changes it.
`active` is what a glance reads: filled while the setting is doing something, a
quiet surface while it is not. Reach for `AppSegmented` wherever there is room
to show every choice at once.
