One measured figure: an overline naming it, the number, and the unit set
quieter beside it. `unit` is its own prop rather than part of the value because
a caller that concatenates the two cannot set them differently — which is what
every screen that wrote this out by hand ended up doing. `size` picks the
figure's step (`lg` for a card's headline number, `md` for one tile in a grid of
them, `xl` for a figure the screen is built around) and `tone="record"` paints
it gold, which as everywhere else means a personal record. The container is the
caller's: a hairline-divided grid cell and a sunken tile are the same stat in
two frames.
