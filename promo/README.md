# One More Rep promo reel

The Reel is a 1080×1920, 19-second, silent MP4 designed for TikTok and Instagram. It intentionally leaves audio empty so a licensed or trending track can be added inside the social platform.

Place the four source screenshots named by `render_reel.swift` in `promo/source`, then render from the repository root:

```sh
swift promo/render_reel.swift
```

Generated media is written to `promo/output` and ignored by Git.
